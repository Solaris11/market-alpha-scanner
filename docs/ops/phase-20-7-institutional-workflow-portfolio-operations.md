# Phase 20.7 - Institutional Workflow + Portfolio Operations

Date: 2026-05-21  
Production commit validated: `e5f6ad1e45d8a496ecb8b022a1adde9e3b6c6e56`

## Scope

Phase 20.7 added a portfolio operations layer to the Paper workflow. The implementation is intentionally evidence-bounded: it uses current paper positions, portfolio intelligence, scenario stress, Strategy Labs simulated allocation history, model revisions, and strategy-family memory. It does not fabricate broker fills, broker rebalances, or institutional compliance state.

## Implemented Systems

### Portfolio Operating Workflows

- Added `buildInstitutionalPortfolioOperationsSystem` in `frontend/src/lib/trading/institutional-portfolio-operations.ts`.
- Added a visible Paper page surface, `InstitutionalPortfolioOperationsPanel`, mounted in `frontend/src/app/paper/page.tsx`.
- The panel shows:
  - operating score
  - open exposure
  - active Strategy Labs mode
  - allocation/concentration lanes
  - fragility budget
  - scenario budget
  - macro exposure
  - liquidity budget
  - shock budget
  - hidden correlation warnings

### Position Lifecycle Tracking

The new model derives lifecycle rows from real `paper_positions` fields and current portfolio context:

- thesis context from setup, sector, and theme
- entry reasoning from scanner/paper decision fields
- stop/invalidation from stored paper stop values
- target/invalidation completeness from stored stop/target fields
- current value from paper exposure
- open risk from stop distance and quantity
- unrealized P/L from stored paper rows

If stop or target data is missing, the UI marks the thesis as incomplete instead of inventing missing discipline.

### Strategy Memory

The operations layer consumes Strategy Labs evidence:

- simulated allocation checkpoints
- completed simulated trade sample count
- strategy-family memory
- model revisions
- drawdown/learning evidence already generated by Strategy Labs

The UI labels this evidence as simulation-derived, not broker execution.

### Professional Workspace Continuity

The panel now links the Paper workflow to:

- Paper portfolio state
- Strategy Labs memory
- scenario stress linkage
- execution workspace limitations

The implementation explicitly marks broker-grade execution workspace persistence as missing.

### Risk Operating Layer

The right-hand operating layer summarizes risk budgets:

- concentration
- fragility
- scenario vulnerability
- macro pressure
- liquidity risk
- shock exposure
- hidden correlation

This is derived from `PortfolioIntelligenceSystem` and scenario stress outputs.

## Remaining Gaps

This phase improves operational seriousness, but it does not fully accomplish institutional portfolio operations.

Remaining gaps:

- No broker integration or broker-grade allocation execution.
- No real rebalance execution ledger from live broker/order records.
- No compliance approval workflow.
- No saved multi-workspace portfolio operating desk with persistent compare/chart/scanner layouts wired into this panel.
- Position thesis history is limited to current paper fields; there is no full thesis revision journal yet.
- Strategy memory is still simulation-derived, not live portfolio performance-derived.
- Mobile was screenshot-validated through production browser automation, not real physical-device certification.
